# Scene Studio: качество и производительность

Обновление от 16 октября 2026 года. Основной layout, палитра, типографика и нижняя панель камер сохранены. Инспектор и диагностика добавлены как закрытые по умолчанию секции левой панели.

## Выполнено

- Транспорт: уплотнители на плоскостях окон, дворники, зеркала мотоцикла, исправленная высота колёс (шины касаются дороги). Сохранены вырезы арок, общие детали, поза водителя и объединение по материалам. По подтверждению пользователя надписи — POLICE, AMBULANCE, FIRE RESCUE.
- Дорога: единая высота асфальта, три неперекрывающихся участка; центр полосы 2,4 м при сохранённой ширине дороги 9,6 м. Автомобили выровнены по этим центрам. Разметка не пересекает стоп-линии и переходы. Общие параметры направлений, въезда/выезда, границ и конфликтной зоны находятся в `roadGeometry.ts`.
- Знаки: перевёрнутый равносторонний треугольник, согласованные лицевые слои, задние пластины, крепления. STOP — отдельный образец библиотеки на площадке, не новая инструкция на подходе к перекрёстку. Символы STOP выполнены геометрией без внешнего шрифта.
- Светофоры: крепления, открытые козырьки и отдельные материалы сигналов. Ручной тест красного, жёлтого, зелёного и выключенного состояния; полноценный контроллер движения не добавлялся.
- Четыре персонажа: разные одежда, волосы, пропорции, трость и рюкзак; выбор и фокус работают для каждого.
- Четыре фасада: жилой с балконами, офис, магазин с навесом, низкий дом со скатной крышей. Окна инстансированы; городские мелочи объединены. Кроны имеют разные формы, масштаб и поворот.
- Инспектор: реальные координаты, поворот в градусах, масштаб, мировой AABB, размеры, треугольники с учётом instancing, геометрии и материалы. Декоративное кольцо не влияет на размеры.
- Asset Preview: тот же объект и общие ресурсы, нейтральный фон, фронтальный/задний/боковой ракурс, вид сверху, свободное вращение и zoom, тени и wireframe. Возврат восстанавливает видимость города.
- День/вечер, одна карта теней; в preview область карты сужается под объект. Матрица теневой камеры обновляется при смене её границ.
- Debug: AABB, мировые оси, центры полос с направлениями, каркас выбранного объекта, helper источника света. Всё выключено по умолчанию.
- Рендер: ограничение фактических отрисовок до 60/30 FPS, demand в покое, остановка на blur/hidden, адаптивный DPR. Счётчики показывают отрисованные кадры, вызовы рендера, треугольники, количество WebGL-геометрий/текстур и CPU-время вызова renderer.render. Это время не является временем GPU.

## Измерения

Одинаковое состояние: все слои и шесть машин включены, активен седан, debug выключен. Это прямой подсчёт созданного R3F scene graph в Node, включая скрытые сигнальные меши и экземпляры InstancedMesh, а не измерение GPU.

| Показатель | До | После |
| --- | ---: | ---: |
| Меши всей сцены | 294 | 271 |
| Треугольники всей сцены | 58 512 | 57 930 |
| Instanced batches | 7 | 12 |

Число мешей уменьшилось на 7,8%, треугольников — на 1,0%. Это не обещание такого же изменения FPS: реальные draw calls зависят от видимости, теней и материалов.

FPS, frame time на устройстве, фактические draw calls, GPU time/нагрузка и WebGL-память до/после не измерены. Подключённого браузера нет, доступ инструмента Computer Use к Chrome не был одобрен системой разрешений. Метрики для пользовательского замера доступны в панели «Рендеринг». WebGL сообщает количество ресурсов, не точный объём видеопамяти в байтах.

## Проверки и воспроизведение

Пройдены 52 теста, ESLint, TypeScript и production build. Тесты покрывают геометрию окон и арок, касание шин дороги, надписи, посадку рук водителя, все регистрируемые объекты в preview, возврат в город, AABB инстансов, восстановление и освобождение wireframe-материалов, положение полос, непересечение разметки, ориентацию дорожных устройств и ограничение фактических render-вызовов при имитации дисплея 120 Гц. При отключении рендера таймеры очищаются.

```sh
npm test
npm run lint
npm run build
npx tsc --noEmit
STUDIO_ASSET_REPORT=1 STUDIO_ASSET_PREVIEW=1 npm test -- --run src/components/scene/scene.test.tsx
```

Последняя команда создаёт технические PNG в `/private/tmp/`: `pdd-vehicle-preview.png`, `pdd-vehicle-preview-rear.png`, `pdd-characters-preview.png`, `pdd-buildings-preview.png`, `pdd-devices-preview.png`, `pdd-city-preview.png`. Они построены из настоящей геометрии с CPU z-buffer, включая instancing, но без PBR и WebGL-теней. Проверены оба ракурса шести машин, персонажи, фасады, знаки, светофор и композиция города. По результатам устранены выступающие крепления знаков и выход витрин за край фасада.

Общие геометрии, материалы и один атлас надписей живут всё время работы библиотеки и не клонируются при переключении preview. Временные helpers и wireframe-копии освобождаются при переключении; instance-буферы освобождаются при размонтировании. Тесты подтверждают эти пути, но длительный тест стабильности GPU-памяти в реальном браузере остаётся непроведённым. LOD не добавлен: при текущем размере сцены и бюджете он усложнил бы систему без подтверждённой пользы.
