# Фаза 5 — чекліст незалежної змістової перевірки

Це завдання для компетентного українського фахівця, а не підтвердження. Джерело для звірки: [чинні ПДР України, постанова № 1306](https://zakon.rada.gov.ua/laws/show/1306-2001-%D0%BF). У записах зазначено редакцію **09.04.2026**, дату дослідження **17.10.2026**; перед підписанням слід повторно перевірити чинну редакцію. Усі вісім записів і три білети мають статус `unverified` / `in_review`.

Для **кожного** пункту перевірити точний текст і номер, винятки та взаємодію з іншими пунктами, межі застосовності у формальній моделі, український переказ і правильність відповіді. Зафіксувати посилання на переглянуту редакцію, дату, ім’я/кваліфікацію рецензента й обґрунтування, прив’язане до незмінних ревізій правила, ситуації та сцени.

| Пункт               | Питання для фахівця                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------------------- |
| 8.7.3 а             | Чи стосується дозволу саме основний круглий зелений; які обов’язки поступитися залишаються?             |
| 8.7.3 е             | Чи правильно відокремлено основний червоний від умов додаткових секцій та інших винятків?               |
| 8.7.3 ґ             | Чи правильно описано жовтий сигнал та попередження про зміну?                                           |
| 8.11                | Чи повністю враховано умову неможливості зупинки без екстреного гальмування та безпеку інших учасників? |
| 16.1                | Чи справді світлофор вимкнено або він блимає жовтим, і чи немає регулювальника?                         |
| 16.6                | Чи охоплено точний напрям зустрічного руху, трамвай, основний сигнал та винятки?                        |
| 16.11               | Чи підтверджена головна/другорядна дорога; чи не змінюється застосовність при повороті головної?        |
| 16.12, абзац перший | Чи справді дороги рівнозначні; чи правильно враховано виняток для кругового руху?                       |

Для **кожного з трьох** білетів (`draft-ua-red-signal`, `draft-ua-left-turn-green`, `draft-ua-secondary-road`) окремо звірити запитання, усі варіанти, правильну відповідь, пояснення й застосовані пункти. Зіставити в 3D автомобілі, початкові напрямки, знаки і сигнали, заявлений маневр та всі інші видимі об’єкти. Підтвердити або виправити невидимі для Scene Definition умови: прив’язку сигналів/знаків до смуг, активність інших учасників, регулювальника, додаткові секції, пріоритет дороги, обмеження смуг, ширини траєкторій і часові інтервали. Наявні автоматичні тести цих фактів не доводять.
