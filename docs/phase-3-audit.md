# Phase 3 — Asset Library Foundation

Архитектурный этап реализован по явному заданию Фазы 3. Расширение ассетов продолжается отдельно;
Фаза 4 не начата. Вторые потребители — Studio и development-only проверка Web.

## Решения

Геометрия и ресурсы извлечены без перерисовки. Studio хранит размещение, выбор, кольцо выделения,
состояние сигналов и настройки сцены. Библиотека получает props и функцию чтения флагов анимации.
Таким образом Zustand не входит в граф зависимостей библиотеки, а кадровый цикл не подписывает модель
на каждое изменение интерфейса. Три знака, четыре персонажа/здания и светофор имеют самостоятельные
компоненты; растительность и мебель пока остаются исходными пакетами размещений ради batching.

Реестр содержит 21 реальную запись. Метаданные доступны отдельно от рендереров, измерения сохраняются
в JSON и проверяются повторным построением каждого объекта. Тесты Studio сверяют габариты каждого
Preview с библиотекой и идентичность общих ресурсов. Публичные exports перечислены явно.
Аудит импортов проверяет приложения и пакеты, включая запрет импорта приложений из библиотеки и
обхода публичных exports. Версии зависимостей сохранены; добавлены только workspace/peer-связи.

Новые категории не выдуманы. Лицензия исходных процедурных ассетов не объявлена в репозитории;
реестр честно фиксирует `unspecified`, а не приписывает MIT/CC0. Ливреи существующей экстренной техники
не объявлены нормативно точными. Украинская совместимость отражает текущий рынок, не юридический вывод.

## Проверки и производительность

Исходные 54 теста сохранены. Дополнительные тесты проверяют реестр, публичные exports, границы,
повторные измерения и каждый Preview Studio. Итог: 101 тест.

| Измерение                               |        До |     После |
| --------------------------------------- | --------: | --------: |
| Mesh в R3F scene graph                  |       271 |       271 |
| Треугольники с учётом instances         |    57 930 |    57 930 |
| InstancedMesh                           |        12 |        12 |
| Studio `.next/static`, байты без сжатия | 1 936 296 | 1 949 206 |
| Web `.next/static`, байты без сжатия    |   934 334 |   938 271 |

Это размеры всех статических сборочных файлов, не объём начальной загрузки страницы и не gzip.
Исходные размеры восстановлены из сохранённого static export Studio и исходного Turbo-артефакта Web.
Рост Studio связан с индексом/метаданными; production Web не содержит реализации Three.js.

Отчёт по каждой машине (mesh / triangles) также совпал: sedan 23/4782, SUV 22/4878,
motorcycle 21/4652, ambulance 27/5192, police 26/5218, fire 31/6836.
Эти значения относятся к исходной Studio-сцене, где у выбранного седана есть кольцо выделения.
Чистая библиотечная модель измеряется без этого кольца.

`pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm check` и `pnpm audit:imports`
успешно выполнены. Studio сохраняет static export.
Web development route `/dev/assets-3d` отвечает 200; production — 404.

В Chrome выполнена ручная визуальная smoke-проверка исходного static export (порт 3101) и нового
static export (3102), одинаковое окно 1918×956, Medium, исходная изометрическая камера.
Геометрия, материалы, композиция и освещение визуально совпадают. В обеих сборках панель показала
241 draw calls, 57.0k видимых треугольников, 150 геометрий и 2 текстуры. Это реальные счётчики
рендерера, а не расчёт по количеству mesh.

При вращении колёс выбранного седана исходная сборка показала 50 FPS / 20.0 ms, новая —
49–50 FPS / 20.0–20.5 ms. Это короткие наблюдения существующей панели при одинаковой нагрузке,
не статистический бенчмарк и не GPU timer query. Существенной регрессии в этом smoke test не видно;
длительный профилинг, mobile и широкий диапазон GPU не проверялись. Числа производительности
отдельных ассетов в реестре остаются null: измерена целая сцена, не каждый объект отдельно.

Новый каталог открыт в браузере; переход из него к изолированному мотоциклу с водителем работает.
На dev-странице Web визуально подтверждён седан, загруженный без Studio. Production-route проверен
по HTTP: 404. Текст fallback Canvas присутствует в дереве доступности даже при рабочем WebGL;
наличие этого текста само по себе не является ошибкой рендера.

## Дальнейшее расширение

Выделение отдельных деревьев/скамеек, новые дорожные категории, измеренные GPU-бюджеты и уточнение
лицензии — отдельная работа. Ни Scene Composer, ни симуляция, ни backend не добавлены.
Инструкции для добавления модели: [README библиотеки](../packages/assets-3d/README.md).
