# РУХ / Scene Studio

Локальная 3D-студия для разработки дорожных сцен. Главная страница `/` содержит только sandbox; учебные билеты, лендинг и маршрут `/trainer` удалены.

## Запуск

```sh
npm install
npm run dev
```

Открыть `http://localhost:3000`. Нужен браузер с WebGL 2 и аппаратным ускорением. Все модели процедурные, сетевые запросы к библиотекам моделей, HDRI, шрифтам и текстурам не требуются.

## Что доступно

- Городской перекрёсток с разметкой, переходами, бордюрами, знаками и светофорами.
- Седан, SUV, мотоцикл, скорая, полиция, пожарная машина.
- Четыре персонажа, четыре варианта зданий, деревья, кусты, фонари, скамейки.
- Независимая видимость объектов и слоёв, выбор активной модели кликом или из списка.
- Свободная камера, изометрия, вид сверху, фокус, плавный переход и сброс.
- Debug-панель: фары, поворотники, аварийный/специальный сигнал, вращение колёс, свет, сетка.
- Low / Medium / High, адаптивный DPR, FPS, время кадра, draw calls и треугольники.
- Инспектор выбранного объекта: трансформация, габариты, треугольники, геометрии, материалы; изолированный просмотр с ракурсами и свободным вращением.
- День / вечер, тени, ручная проверка сигналов светофора; bounding boxes, оси, центры полос, wireframe и направление света. Новые инструменты находятся в сворачиваемых секциях существующей панели.

Переключение спецсигналов и колёс — просмотр модели на месте, а не симуляция дорожного движения. Сигналы относятся к выбранной модели. Фары включаются для всего транспорта. При выборе другой модели анимационный предпросмотр сбрасывается.

## Архитектура

```text
src/app/                         единственная страница и глобальные стили
src/components/layout/           оболочка студии
src/components/debug/            каталог, настройка, метрики
src/components/ui/               SVG-превью объектов
src/components/scene/
  resources.ts                   общие геометрии и материалы
  Primitives.tsx                 базовые элементы и instanced batches
  vehicles/                      транспорт
  characters/                    персонажи
  environment/                   здания, озеленение, городские детали
  roads/                         перекрёсток
  signs/                         дорожные знаки
  traffic-lights/                светофоры
  camera/                        OrbitControls и переходы
src/stores/                      состояние студии (Zustand)
src/hooks/                       остановка рендера в неактивном окне
src/lib/                         каталог и профили качества
src/types/                       типы студии
```

Новые модели добавляются в `studioConfig.ts` и `VehicleModel.tsx`. Сценические объекты не зависят от билетов или правил ПДД: будущую предметную логику можно подключить отдельным слоем.

## Производительность

- `frameloop="demand"`: неподвижная сцена не запускает непрерывный рендер.
- Реальные вызовы рендера ограничены 60 или 30 FPS; анимации запрашивают следующий кадр одноразовым таймером. В покое и в скрытой вкладке таймеры отключены. Во время управления камерой её обработчики могут обновляться чаще отрисовки.
- При скрытой вкладке или потере фокуса — `frameloop="never"`.
- Анимационный цикл включается только для видимого активного объекта по запросу пользователя.
- Пул геометрий и материалов, объединённая геометрия дисков; окна, разметка, бордюры и зелень используют instancing.
- Нет постпроцессинга, загрузки HDRI, прозрачных стёкол или анимированных городских объектов.
- Low отключает тени. Medium/High используют одну карту мягких теней 1024/2048; она обновляется при изменении сцены, а не при каждом движении камеры. DPR временно снижается во время работы с камерой.
- Метрики поступают в UI с ограниченной частотой. При остановке рендера показан последний FPS, а не вымышленный показатель для неподвижной сцены.

Реальный FPS зависит от GPU, разрешения и браузера; его нужно измерять на целевом устройстве. Изначально выбран Medium.

## Проверки

```sh
npm run lint
npm test
npm run build
npx tsc --noEmit
```

`next build` обновляет сгенерированные типы маршрутов; после удаления страниц проверку TypeScript нужно запускать после сборки. Статический экспорт — в `out/`.

Тесты монтируют реальный R3F scene graph в Node: проверяют сборку всех объектов, ограничения на меши и полигоны, выбор модели кликом, сторону поворотников, предпросмотр колёс и переходы камеры. Это проверка компонентов и геометрии, а не замена визуального QA в браузере.

Подробнее об обновлении, измерениях и ограничениях: [docs/SCENE_STUDIO_UPGRADE.md](docs/SCENE_STUDIO_UPGRADE.md).
