# РУХ / Traffic Laws

Образовательная платформа ПДД Украины. На Фазе 1 в репозитории есть только существующая 3D Scene Studio. Интерфейс, модели, камеры и освещение сохранены.

## Запуск

Нужен Node.js 24 LTS. Рекомендуемая версия указана в `.nvmrc`; проверено также на установленном Node.js 24.12.0.

```sh
nvm install
nvm use
npm install --global pnpm@10.34.7
pnpm install
pnpm dev
```

Если Node.js уже установлен без nvm, первые две команды не нужны. Открыть http://localhost:3000. Studio требует WebGL 2 и аппаратного ускорения.

## Команды из корня

| Команда              | Назначение                                              |
| -------------------- | ------------------------------------------------------- |
| `pnpm dev`           | Запуск Studio                                           |
| `pnpm build`         | Production build и статический экспорт                  |
| `pnpm typecheck`     | Генерация типов маршрутов и строгая проверка TypeScript |
| `pnpm lint`          | ESLint для инфраструктуры и Studio                      |
| `pnpm test`          | Все тесты Studio                                        |
| `pnpm format`        | Форматирование новых конфигураций и документации        |
| `pnpm format:check`  | Проверка форматирования                                 |
| `pnpm audit:imports` | Циклы локальных импортов и необъявленные зависимости    |
| `pnpm check`         | Все перечисленные проверки и сборка                     |

Результат сборки: `apps/studio/out/`. Сохранён `output: "export"`, поэтому `next start` не используется: production размещается на статическом хостинге.

## Структура

- `apps/studio/` — единственное Next.js-приложение, включая исходники и тесты.
- `packages/` — место для будущих общих модулей; сейчас только описание.
- `tooling/` — общие конфигурации TypeScript и ESLint.
- `scripts/` — проверки репозитория.
- `docs/` — архитектура, руководство разработчика и отчёты.

Зависимости управляются pnpm, фиксируются в `pnpm-lock.yaml`. В CI используйте `pnpm install --frozen-lockfile`. Не создавайте второй lockfile через npm install.
